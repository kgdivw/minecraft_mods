# Golem Mod

De **Ultra Golem**: de sterkste golem van de hele wereld. Hij valt **alles** aan wat beweegt — zombies, skeletten, creepers, de warden, koeien, dorpelingen — **behalve jou**. Jij kunt hem ook niet per ongeluk raken.

## Hoe krijg je een golem?

1. **Craft een Golem Hart** in een crafting table: 4x ijzerblok in de hoeken, 4x diamant ertussen en 1x redstoneblok in het midden.
   ```
   I D I
   D R D     I = ijzerblok, D = diamant, R = redstoneblok
   I D I
   ```
2. Of typ in de chat `/function golem` — dan krijg je meteen **5 Golem Harten**.
3. **Klik met het hart op de grond** en je Ultra Golem staat er. Elk hart = 1 golem, dus je kunt een heel leger maken.

## Hoe sterk is hij?

| | |
| --- | --- |
| Leven | **1000** (een warden heeft er 500) |
| Schade per klap | **250** (bijna alles gaat in één klap om) |
| Knockback | **0** — hij is niet weg te duwen |
| Immuun voor | vuur, lava, vallen, verdrinken, magie, wither **en jouw eigen klappen** |

## Wat doet hij?

- Hij zoekt zelf monsters op tot **40 blokken** ver en andere mobs tot **24 blokken** ver, en rent er meteen op af.
- Hij loopt door water, klimt tegen muren op en doet deuren open.
- Hij valt **nooit** een speler aan, ook niet als je hem slaat.
- Andere Ultra Golems laat hij met rust — jouw leger vecht niet met zichzelf.
- Loop je meer dan 64 blokken weg? Dan teleporteert hij naar je toe, zodat je hem nooit kwijtraakt.
- Hij verdwijnt niet vanzelf, en je kunt hem een naam geven met een naambordje.

1. Download `GolemMod.mcaddon` van de [laatste release](../../releases/tag/latest)
2. Open het bestand — Minecraft importeert de addon automatisch
3. Zet in je wereldinstellingen **zowel** het behavior pack als het resource pack aan
